Intro to Node.js

Lecture 09 · Part I

1) Client vs Server

  • Client-side = HTML, CSS, JS รันในเบราว์เซอร์
  • Server-side = เลือกว่าจะส่งเนื้อหาอะไรกลับ (PHP, Python, Ruby, C#, Node.js) เข้าถึง file system ของเครื่องได้เต็มที่

2) ลำดับ Request / Response

  1. Client ส่ง HTTP GET ไปที่ Web Server
  2. เป็น static → ส่งไฟล์กลับเลย
  3. เป็น dynamic → ส่งต่อให้ Web Application อ่าน DB
  4. นำข้อมูลรวมกับ HTML template แล้วตอบกลับ
Server = IP + Port เช่น localhost:3000, 10.34.111.111:8080 พอร์ตที่เจอบ่อย: 3000, 8080, 8081

Node.js คืออะไร

  • Asynchronous JavaScript runtime สร้างบน V8 engine ของ Chrome — open-source server environment
  • ไม่มี DOM (document, window) และไม่มี Cookies แบบเบราว์เซอร์ แต่มี module พิเศษ เช่น File system, HTTP
  • Single thread event loop: thread หลักรับ request → ส่งงานให้ File System / Database / Computation → ไม่รอ (non-blocking) รับ request ถัดไปได้ทันที → งานเสร็จค่อยตอบกลับ
เหมาะกับ
I/O หนัก, real-time, scalable, JSON API, ใช้ JS ภาษาเดียวทั้งระบบ
ไม่เหมาะกับ
งานคำนวณหนัก (computation-intensive)

เริ่มใช้งาน + Global Objects

  • ติดตั้ง LTS จาก nodejs.org · ตรวจด้วย node --version · รันด้วย node filename.js
  • console.log() ใน Node ไม่ใช่ window.console.log()
  • Global objects ใช้ได้ทุกไฟล์ ไม่ต้อง import: __dirname (โฟลเดอร์ปัจจุบัน), __filename (path เต็มของไฟล์), exports, module, require(), console, process, global

Module System

  • ทุกไฟล์ JS = 1 module ตัวแปร/ฟังก์ชันเป็น private ภายในไฟล์ ชื่อซ้ำกันข้ามไฟล์ไม่ทับกัน
// hello.js — ส่งออก (export)
function sayHello(){ console.log("Hello"); }
module.exports.sayHi = sayHello;

// app.js — นำเข้า (import)
const eng = require("./hello");   // ไฟล์ของเรา ใช้ ./ นำหน้า
eng.sayHi();                       // → Hello

export ได้ทั้งค่าตรง ๆ module.exports = "Hello", property module.exports.x = ..., หรือฟังก์ชัน

fs: Async vs Sync และ Callback Hell

Async (non-blocking)

ใช้ callback function(err, contents) อ่าน 3 ไฟล์พร้อมกัน → ลำดับผลลัพธ์อาจสลับกันได้ ในแต่ละครั้งที่รัน

Sync (blocking)

readFileSync รอจนเสร็จก่อนบรรทัดถัดไป → ลำดับแน่นอน แต่หยุดการทำงานอื่น

  • อยากการันตีลำดับ: ใช้ Sync หรือซ้อน callback
  • ซ้อน callback เป็นขั้นบันได }) = Callback Hell (อ่านยาก ดูแลยาก) → ใช้ Promise หรือ async/await แทน

สร้าง Server ด้วย http

const http = require("http");
const myServer = http.createServer((req, res) => {
  res.statusCode = 200;                          // 200 = OK
  res.setHeader("Content-Type", "text/plain");
  res.write("Hello World!");
  res.end();                                     // จบการตอบกลับ
});
myServer.listen(8081, () => console.log("Listening on 8081"));
  • req.url = path ที่ขอ, req.method = GET/POST · เปิด http://localhost:8081 · หยุดด้วย Ctrl+C
  • เบราว์เซอร์มักขอ /favicon.ico เพิ่มอีก 1 request

Routing เอง (if / else if)

if (req.url === "/")           { /* ข้อความ greeting */ }
else if (req.url === "/shabu") { fs.readFile("./shabu.html", ...) // Content-Type: text/html }
else if (req.url === "/bbq")   { /* ส่ง bbq.html */ }
else { res.statusCode = 404; res.write("Invalid requested :("); res.end(); }

Express Framework

Lecture 10 · Part II

Express Framework

  • web framework ที่ minimal และ flexible ช่วยเรื่อง routing, สร้าง API, ใช้ร่วมกับ template engine (Pug, EJS) ที่แทนตัวแปรในไฟล์ template ด้วยค่าจริงแล้วสร้างเป็น HTML

ตั้งโปรเจกต์ Express (ทำตามลำดับ)

ขั้นคำสั่ง / ทำอะไรผล
1npm initสร้าง package.json (metadata, entry point main)
2npm install expressลง Express + เพิ่มใน dependencies
3npm install nodemonrestart server อัตโนมัติเมื่อไฟล์เปลี่ยน (ไม่บังคับ)
4สร้าง app.jsไฟล์หลัก: routes + ตั้งค่า server
5ใน scripts ใส่ "start": "nodemon app.js"รันด้วย npm start

npm = package manager สำหรับติดตั้งแพ็กเกจเพิ่มให้ Node.js · โครงโฟลเดอร์: node_modules/, package.json, app.js, html/

โครง app.js พื้นฐาน

const express = require('express');
const port = 3000;
const app = express();                       // สร้างแอป

app.get('/', (req, res) => {                  // route: GET /
  res.send('Hello World from Root!');
});

app.listen(port, () => console.log(`Server listening on port: ${port}`));

Routing ด้วย express.Router()

  • Middleware = ฟังก์ชันที่เข้าถึง req และ res ได้
  • เส้นทางหนึ่งประกอบด้วย HTTP method + path เช่น GET /shabu, POST /user/add
const router = express.Router();
app.use(router);                              // ลงทะเบียน router

router.get('/shabu', (req, res) => {
  res.sendFile(path.join(`${__dirname}/html/shabu.html`));  // ส่งไฟล์ HTML
});

// ★ วางท้ายสุด: ดักทุก path ที่ไม่มีใครรับ (ทุก method)
router.use((req, res, next) => {
  res.status(404).send("Invalid Path");
});
จำ: __dirname = path โฟลเดอร์ปัจจุบัน · path.join = ต่อ path · ลิงก์ใน navbar href="/shabu" ต้องตรงกับ route ใน app.js

Serving Static Files (CSS / รูป / JS ฝั่ง client)

app.use('/', express.static(path.join(__dirname, 'public')));   // ตั้งโฟลเดอร์ static
<!-- ใน HTML อ้างจากโฟลเดอร์ static เป็น root -->
<link rel="stylesheet" href="/mystyle.css">   // ไม่ใช่ ../public/mystyle.css

Modular Routes (เว็บใหญ่ขึ้น)

app.use("/product", router1);      router1.get('/add', ...)  → /product/add
app.use("/user",    router2);      router2.get('/add', ...)  → /user/add

path ที่ mount (/product) + path ใน router (/add) = URL เต็ม

Form Handling: GET vs POST

  • ตรวจข้อมูลที่เบราว์เซอร์ (HTML5/JS) เมื่อทำได้ และตรวจซ้ำที่ server ถ้าจะลง DB
  • แอตทริบิวต์ใน <form>: action = ปลายทาง (เช่น /form-get) · method = GET/POST · ค่าอ้างผ่านแอตทริบิวต์ name ของ input
  • path และ method ใน route ต้องตรงกับ action และ method ในฟอร์ม
GETPOST
ข้อมูลอยู่ที่URL หลัง ? เช่น ?fname=John&lname=Doemessage body
อ่านใน Expressreq.query.fnamereq.body.fname
ต้องมี middleware?ไม่ต้องต้อง: express.json() และ express.urlencoded({extended:true})

  res.send(`Form submitted by ${req.body.fname} ${req.body.lname} with ${req.method}`);
});

Cookie ใน Express

  • เซิร์ฟเวอร์ส่งเฮดเดอร์ Set-Cookie → เบราว์เซอร์เก็บ → ส่งกลับในเฮดเดอร์ Cookie ทุก request
const cp = require("cookie-parser");
router.use(cp());                                   // ต้องมีก่อนอ่าน req.cookies

res.cookie('tokenID', 'some-random-id');            // สร้าง
req.cookies;                                        // อ่านทั้งหมด
req.cookies['tokenID'];                             // อ่านตามชื่อ
res.cookie('x', 'v', { maxAge: 360000 });           // อายุ (มิลลิวินาที)
res.clearCookie('tokenID');                         // ลบ
ตัวอย่าง Login/Logout: /login สร้างคุกกี้ tokenID · /restrict ตรวจคุกกี้ ถ้าไม่มีตอบ 401 · /logout ใช้ clearCookie (จริง ๆ ต้องตรวจ user/password ก่อนสร้าง token)

Session ใน Express

const session = require('express-session');
router.use(session({
  secret: process.env.SESSION_SECRET,  // ลงนาม session ID
  resave: false,                       // บันทึกเฉพาะเมื่อ session เปลี่ยน
  saveUninitialized: true,             // สร้าง session ให้ทุกผู้ใช้ แม้ยังไม่ใช้
}));

req.session.numviews = (req.session.numviews || 0) + 1;   // สร้าง/อ่าน/อัปเดต
  • เข้าถึง req.session.ชื่อ ได้จากทุก route · MemoryStore (ค่า default) ใช้สำหรับ debug/พัฒนา ไม่ใช้บน production

Node.js + MySQL (mysql2)

  • ติดตั้ง npm install mysql2 · ใช้ MySQL Server + MySQL Workbench จัดการ DB
  • เตรียม: สร้าง DB/ตาราง (เช่น tinycollege.sql) → สร้าง user (username, password, host=localhost) → กำหนด privilege
  • SQL พื้นฐาน: SELECT (WHERE, GROUP BY, HAVING, ORDER BY), INSERT, UPDATE, DELETE
const mysql = require('mysql2');
const connection = mysql.createConnection({
  host: process.env.MYSQL_HOST,      user: process.env.MYSQL_USERNAME,
  password: process.env.MYSQL_PASSWORD, database: process.env.MYSQL_DATABASE
});
connection.connect(err => { if (err) throw err; console.log("Connected DB"); });

// SELECT → results คือ array ของแถว
router.get("/cis-courses", (req, res) => {
  const sql = `SELECT course_code, course_name FROM Course WHERE dept_code='CIS'`;
  connection.query(sql, (error, results) => {
    if (error) throw error;
    res.send(results);                          // ส่งเป็น JSON
  });
});
// INSERT → results.affectedRows ; แล้ว res.redirect("/cis-courses")

สไลด์ใช้ GET เพื่อ INSERT แค่ตัวอย่าง จริง ๆ ควรใช้ POST · mysql2 รองรับ Promise และ async/await
